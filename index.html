우리 회사는

개발 포인트
추천 모델 서빙에 추론 최적화 런타임(TensorRT LLM 등) 적용을 검토하고, 적용 전후 응답시간·GPU 비용을 비교하자.

  2. AI에게 '이 탭을 보고 가격·취소 규정·입실 시간을 정리해 달라'고 시킨다.
  3. AI가 틀리게 읽은 항목(가격 단위, 환불 조건, 날짜)을 그대로 적어 둔다.
  4. 틀린 부분이 이미지 속 글자인지, 글로 적혀 있는지 표시한다.
  5. 목록을 운영·기획 채널에 올려 이번 주 수정 대상으로 공유한다.

고객이 AI에 우리 페이지를 읽히는 상황이 생긴다. AI가 잘못 읽은 환불 규정은 CS 문의와 분쟁으로 돌아온다.
