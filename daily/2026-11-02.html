ChatGPT 계정 탈취 가능했던 취약점 공개

보안업체가 ChatGPT의 HTML 미리보기 기능에서 계정 탈취 경로를 찾았다.

Parameter Labs가 ChatGPT의 '아티팩트' 기능(대화 안에서 HTML 앱을 실행해 보여 주는 기능, 과거 Canvas·현재 HTML 미리보기) 구현에서 결함을 찾았다고 밝혔다. 이 기능은 외부 코드가 OpenAI API나 개인 데이터에 접근하지 못하도록 격리(샌드박스)해야 하는데, 여러 단계를 엮은 복잡한 공격 사슬이 발견됐다.

왜 중요?
AI 제품이 사용자 코드를 실행하면 데이터 유출 경로가 생긴다는 경고.
개발 포인트
제품에서 사용자·모델이 만든 HTML을 렌더링한다면 iframe 격리 설정과 같은 출처(origin) 분리를 점검하라.
