C5 · 오늘 바로 써먹을 팁

영수증·예약 서류 OCR 10분 테스트

  1. 실제 업무 이미지 5장을 고른다 (영수증, 숙박 바우처, 신분증 가림 처리본 등).
  2. OCR(이미지 속 글자 인식) 모델에 같은 프롬프트로 5장을 넣고 결과를 텍스트로 받는다.
  3. 금액·날짜·인원처럼 틀리면 안 되는 필드만 골라 정답과 대조해 정확도를 센다.
  4. 틀린 항목의 패턴(흐림, 손글씨, 표 구조)을 메모해 자동화 적용 범위를 나눈다.
  5. 정확도가 낮은 구간은 사람 검수 단계로 남기고, 나머지만 자동 입력 후보로 정리한다.
