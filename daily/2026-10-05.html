C5 · 오늘 바로 써먹을 팁

10분 만에 AI 호출 '요금 폭탄' 차단선 걸기

  1. 쓰고 있는 LLM(대형 언어 모델) API 키를 목록화하고, 콘솔에서 월 예산 상한과 알림 임계치를 먼저 설정한다.
  2. 개발·스테이징 키를 운영 키와 분리하고, 개발 키에 더 낮은 상한을 건다.
  3. 코드에 호출당 max_tokens 상한과 재시도 횟수 제한을 명시해 무한 루프 비용을 막는다.
  4. 에이전트가 도구를 자동 호출하는 구간에 '최대 N스텝' 카운터를 넣고, 초과 시 중단하고 로그를 남긴다.
  5. 최근 7일 사용량을 기능별로 쪼개 보고, 상한 대비 여유가 적은 기능은 캐싱 대상으로 표시한다.

에이전트가 스스로 API를 호출하는 구조에서는 버그 하나가 곧 과금으로 이어진다. 상한과 스텝 제한은 큰 코드 수정 없이 10분 안에 걸 수 있는 가장 싼 보험이다.
