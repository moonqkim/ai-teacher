딥시크, 검색·페치 API 1000건에 0.75달러

딥시크가 웹 검색·문서 가져오기 기능을 성공 요청 1000건당 0.75달러에 내놨다.

중국 AI 기업 딥시크가 검색(search)과 가져오기(fetch) 두 가지 기능을 API(프로그램끼리 주고받는 연결 창구) 형태로 공개했다. 가격은 성공한 요청 1000건 기준 0.75달러로 표기돼 있다. 해커뉴스에서 182점, 댓글 83개를 기록하며 개발자들의 관심을 모았다.

왜 중요?
AI가 웹을 읽어오는 비용이 공개 가격표로 비교 가능해졌다.
개발 포인트
지금 쓰는 검색 API 단가와 0.75달러/1000건을 직접 비교해 보고, 실패 요청 과금 여부·응답 품질을 소규모로 먼저 테스트해 보자.

현대차·기아, 제조 현장용 AI 에이전트 공개

현대차·기아가 공장 공정을 말로 묻고 시뮬레이션하는 AI 에이전트를 시연했다.

현대차·기아는 의왕연구소에서 '이포레스트 테크데이 2026' 사전 미디어 행사를 열고 제조 특화 AI 에이전트 '이포레스트 폴라리스'를 시연했다. 진행 중인 가상 시운전·안전 작업 현황을 대화로 답하고, '통신 전파 상황을 시뮬레이션해줘'라고 하면 연구실 공간 위에 전파 세기를 색으로 표시했다. 올해 테크데이에선 200여 건의 제조 기술이 소개된다.

왜 중요?
현장 운영을 대화로 확인하는 방식이 제조업에 들어오기 시작했다.
개발 포인트
사내 데이터를 대화형으로 묻는 에이전트는 '현황 조회 + 시각화 연동'이 핵심이니, 먼저 조회 가능한 운영 데이터와 3D·공간 데이터를 도구(tool)로 노출하는 구조부터 설계해 볼 만하다.
